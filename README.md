WordPress Plugins, Themes & Development Tools

A curated collection of custom WordPress themes, plugins, and internal client management tools showcasing production-ready WordPress engineering, clean architecture, and administrative UI development.

---

Projects Overview

1. CoreFlex (WordPress Approved)
Package: coreflex.zip (https://wordpress.org/themes/coreflex/)

A lightweight, high-performance WordPress theme tailored for modern business sites. Built adhering strictly to the WordPress template hierarchy, it features comprehensive Customizer integration, dynamic widget areas, responsive navigation, and out-of-the-box WooCommerce compatibility.

Stack: WordPress, PHP, HTML5, CSS3, JavaScript


2. NovaPress Core
Package: novapress-core.zip ([https://github.com/mdshasan/Plugins-and-themes/blob/main/novapress-core.zip](https://github.com/mdshasan/Plugins-and-themes/blob/main/novapress-core.zip))

A modular backend engine designed to manage structured business directories. Illustrates robust plugin architecture, secure WordPress Hooks (actions/filters), custom administrative interfaces, and modular shortcode-driven rendering.

Stack: WordPress Plugin API, PHP, Custom Post Types, Admin UI, Shortcode API

3. StateKeeper
Package: statekeeper-v2.4.0.zip ([https://github.com/mdshasan/Plugins-and-themes/blob/main/statekeeper-v2.4.0.zip](https://github.com/mdshasan/Plugins-and-themes/blob/main/statekeeper-v2.4.0.zip))

An integrity monitoring and targeted file-recovery utility for WordPress administrators. Tracks unauthorized file mutations, flags anomalous updates via scheduled jobs, and enables granular restoration from verified snapshots without full-site downtime or overwriting untouched data.

Key Capabilities: Automated snapshot generation, file differential analysis, targeted file rollback
Stack: WordPress Filesystem API, WP-Cron, PHP, Security Audit Dashboards

Repository Scope

This repository serves as an engineering portfolio and reference library. Each codebase illustrates key facets of practical WordPress engineering: secure data handling, nonces and capability checks, scalable plugin architecture, performant template rendering, and bespoke administrative tooling.

---

Installation Guide

1. Download the target project ZIP file from the links above.
2. Sign in to your local or staging WordPress administration panel.
3. For plugins:
Navigate to Plugins > Add New Plugin > Upload Plugin.
4. For themes:
Navigate to Appearance > Themes > Add New Theme > Upload Theme.
5. Upload the archive, click Install Now, and activate the extension.
